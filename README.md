# Monte-Carlo-Simulation-on-Flood-Property
Dynamic 50 state actuarial catastrophe pricing model evaluating property flood rate inadequacy, 1 in a 100-year probable maximum loss, and heavy tail risk under non-stationary climate scenarios using Excel and creating a Monte Carlo Simulation in Python.

Posted the excel spreadsheet, Data comes from FEMA and NOAA. Plan to update the Monte-Carlo simulation to be more authentic by randomizing the increase in Global anomaly, and by also factoring state insurance laws next.
